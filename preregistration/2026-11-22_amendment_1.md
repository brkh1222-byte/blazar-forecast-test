# Amendment 1 (2026-11-22): deviations from predictions_2026.md

1. **Commit timing.** `predictions_2026.md` was written before any Part B light curve was
   downloaded, but the tool environment blocked the git commit. Its SHA-256 and those of the
   analysis code were recorded in `results/prereg_fingerprint.txt` at 2026-11-21T23:41:33Z,
   before the download. The file is committed later by the author, unchanged; the hashes let
   anyone check that.
2. **LCR names.** Two 4FGL names in Peñil et al. Table 1 are not LCR names. OJ 014 is
   `4FGL J0811.4+0146` and 87GB 164812.2+524023 is `4FGL J1649.4+5235` in the LCR.
   `data/penil_sources.csv` was corrected. No analysis choice changed.
3. **Regular time grid.** Some LCR light curves lack a few 30-day bins (fit failures).
   Light curves are placed on the regular grid MJD 54698 + 30k (211 bins to MJD 61000), and
   missing bins count as not detected.
4. **Exploratory rule X1 (added after seeing Q0).** No pre-registered rule reached κ ≥ 0.7
   (best: R3, κ = 0.34), so by §3 there is no primary rule. After seeing this, we tried simple
   AND-combinations of the candidates; R3 AND R4 ("X1") agreed best (κ = 0.47). X1 is reported
   as **exploratory only**: it was chosen using the Table A7 verdicts, so its p-value is not a
   confirmatory test.
5. **Effect size reported as a rate difference.** The pre-registered effect size (observed hits
   minus null-mean hits) is biased upward, because shifted forecasts in N1 can leave the data and
   become non-evaluable. R0, which can never miss, shows the size of this bias: its "excess" is
   +3.5 hits (95% interval 2.0–5.1) with no information at all. We therefore report
   ΔH = H_obs − mean(H_null) with the null standard deviation, and keep the hit-count excess in
   `results/partB_n1.csv` for completeness.
