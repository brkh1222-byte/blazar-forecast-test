# CLAUDE.md

This is a research project by an independent astrophysics researcher. It calibrates the forecast-hit rate reported by Peñil et al. 2026 (arXiv:2606.15676) against red-noise and randomised-forecast nulls, and pre-registers a test of their new predictions. Never edit `preregistration/` after it is committed; add amendments as new dated files. Read PROPOSAL.md first, then notes/STATUS.md for the current state. A mentor who works on cosmology and black holes may co-author.

- **Stack:** Python with numpy, scipy, astropy (LombScargle), emcee and matplotlib. Data comes from the Fermi LAT Light Curve Repository API. Keep it simple; no Fermi Science Tools.
- **Statistics matter most:** every periodicity claim must be calibrated against red-noise simulations (Timmer & König / Emmanoulopoulos). Never report a significance without them.
- **Reproducibility:** pin versions in `requirements.txt`. Every figure and table must be regenerable from a script.
- **Working mode and integrity (updated 2026-11-25):** the researcher pilots. Claude runs the project and drafts the paper; the researcher edits it afterwards and is responsible for the content. Authorship is undecided: use the placeholders `[AUTHORS — TBD]` and `[AI-USE STATEMENT — TBD]` in the paper. The paper must carry an accurate AI-use disclosure, and the current arXiv and AAS policies on generative AI must be checked before submission (authors are fully responsible for the content; AI tools cannot be authors). Explain methods when implementing them. Verify every citation, and list every number in the paper with its source in `paper/notes.md`.
- **Pre-registration:** files under `preregistration/` are committed by the researcher personally, never by Claude. Deviations go in new dated amendment files. Do not download or inspect light-curve data after MJD 61205 (2026-06-14) for the Part C sources before each forecast's scoring date.
- **Environment:** `uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt`; run tests with `.venv/bin/python -m pytest -q`.
